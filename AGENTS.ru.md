# Инструкции для работы с репозиторием

Это исходная русская версия. Агенты используют английский [AGENTS.md](AGENTS.md). При изменении правил сначала обновляйте этот файл, затем полностью синхронизируйте английский перевод в той же задаче; не создавайте противоречащих правил.

## Проект

Scratches — расширение VS Code на TypeScript для работы с временными файлами. Описание поведения и запуск находятся в [README.md](README.md), карта компонентов и точек изменения — в английском [EXTENSION_MAP.md](EXTENSION_MAP.md), используемом агентами. Основная русская версия карты — [EXTENSION_MAP.ru.md](EXTENSION_MAP.ru.md): сначала обновляйте её, затем синхронизируйте английский перевод в той же задаче. `package.json` задаёт публичные настройки, команды, представления и меню; реализация находится в `src/`.

## Работа над изменениями

- Перед изменениями изучите затронутый поток, манифест, вызывающий код и тесты; сохраняйте существующие пользовательские изменения.
- Сохраняйте совместимость идентификаторов команд, настройки `scratches.path`, формата хранилища и поведения представлений. Если изменение контракта необходимо, явно опишите его и предусмотрите миграцию.
- При изменении команд и представлений согласуйте регистрацию в коде с объявлениями, меню и условиями в `package.json`. Учитывайте повторную настройку и освобождение ресурсов VS Code.
- Файловые операции работают с пользовательскими данными: проверяйте границы путей, конфликты, ошибки и частичный успех; не допускайте неожиданной перезаписи или удаления. Тестируйте их во временных директориях.
- Пишите код и идентификаторы на английском; комментарии объясняют намерение и ограничения. Следуйте действующим настройкам TypeScript и ESLint, не обновляйте зависимости без необходимости.
- Добавляйте осмысленные тесты поведения для изменений, соразмерные риску. Не считайте шаблонный тест существующим покрытием функциональности.

## Проверка

После установки зависимостей через `npm ci` используйте `npm run compile` и `npm run lint`; для изменений поведения запускайте `npm test` (Extension Development Host может потребовать загрузку VS Code). Сообщайте о непроверенном и причинах. Для изменений только документации проверьте факты по исходному коду, ссылки и итоговый diff. При изменении архитектуры или пользовательского поведения обновляйте карту и README по необходимости.
